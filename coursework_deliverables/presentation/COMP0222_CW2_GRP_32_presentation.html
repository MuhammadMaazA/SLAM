Q3 — LiDAR SLAM with Own Sequences

Data Collection · ICP Odometry · Loop Closure · Factor Graph Optimisation

3 Sequences (Q3 brief)

  • Floor7_Hallway — indoor large area (Marshgate L7 corridors)
  • Basement_1 — indoor compact
  • Outdoor_1 — outdoor (One Pool St.)
  • Protocol: exactly 2 loops, marked start/end
  • Proximity-based lap detection
  • Blind-spot mask: 135–225° (operator)
  • Quality filter: q ≥ 5 (of 63)

ICP Pipeline

  • Distance filter: 10–12,000 mm
  • Voxel centroid downsampling
  • PCA normals (k=5 neighbours)
  • Point-to-plane ICP + Huber IRLS
  • Divergence rejection (≤0.5m, ≤25°)
  • Fixed: relative dT, not absolute heading
  • Keyframe: Δdist>0.2m or Δangle>0.2rad
  • Local map: last 20 keyframes

Loop Closure + Factor Graph

  • Gate 1: temporal separation ≥ 10 KF
  • Gate 2: adaptive arc gate (≥8m or 40%)
  • Gate 3: pose distance ≤ 2.0m
  • Gate 4: ICP overlap score ≥ 0.70
  • NMS: 15 KF window per revisit
  • GTSAM Pose2 LM (200 iter)
  • Fixed: per-loop ICP Hessian propagated

Max Range

  • 2,000 mm vs 12,000 mm

Angular Res.

  • Full / n=2 / n=3

Voxel Grid

  • None / 0.05 / 0.10 / 0.20m

Scan Rate

  • All / 50% / 33%

Q3b — Occupancy Grids per Parameter Setting

Basement_1 · Log-odds grid, Bresenham ray-casting, 0.05m cells · Dynamic grid sizing

Max Range: 2,000 mm (poor) vs 12,000 mm (sensor max, full map)

Voxel Grid: None / 0.05m / 0.10m / 0.20m — detail vs noise trade-off

Key observation: 2,000mm range clips walls ICP uses for heading estimation → accumulated drift visible as map duplication. Voxel=0.05m optimally balances sensor noise averaging with surface-feature preservation.

Q3c — Loop Closure Detection

4-gate pipeline · ICP match score bimodal histogram · NMS to prevent duplicate factors

Q3c: Loop closure analysis (Basement_1). Left: accepted closures (magenta arcs); Right: ICP score distribution

4-Gate Filter

  • Gate 1: j−i ≥ 10 KF (temporal)
  • Gate 2: arc ≥ min(8m, 40% total) (adaptive)
  • Gate 3: pose dist ≤ 2.0m (geometric)
  • Gate 4: ICP score ≥ 0.70 (photometric)

Threshold Justification (0.70)

  • Sliding-window false matches: 0.45–0.60
  • Confirmed revisits: 0.75–0.95
  • Clear bimodal gap (see histogram)
  • Observed consistently across all 3 seqs
NMS (15 KF window) collapses each physical revisit to one factor, preventing over-constraining the pose graph.
